构造方法

没有在构造方法中初始化字段时，引用类型的字段默认是null，数值类型的字段用默认值，int类型默认值是0，布尔类型默认值是false

一个构造方法可以调用其他构造方法，调用其他构造方法的语法是this(…)

继承 is

在Java中，任何class的构造方法，第一行语句必须是调用父类的构造方法。如果没有明确地调用父类的构造方法，编译器会帮我们自动加一句super()

子类不会继承任何父类的构造方法。子类默认的构造方法是编译器自动生成的，不是继承的

sealed 用于限制一个类或接口允许哪些类型继承或实现。

表示 Shape 只允许 Circle 和 Rectangle 继承。

直接继承 Shape 的子类必须声明为以下三种之一：

  • final：不能再被继承
  • sealed：继续限制它的子类
  • non-sealed：解除限制，允许任意类继承

异常

  • Checked Exception 必须处理：要么 catch，要么 throws。
  • catch：我在这里处理异常。
  • throws：我不处理，交给调用我的方法处理。
  • throw：真正抛出一个异常对象。
  • 异常会沿着调用栈向上传递：
关键字 作用 写在哪
throw 真正抛出一个异常对象 方法体里面
throws 声明这个方法可能抛异常 方法声明后面

多个 catch：子类异常放前面，父类异常放后面；否则编译不过。

捕获异常后再次抛出时，尽量保留原始异常作为 cause。

知识点 作用
throw new XxxException() 主动抛异常
异常传播 当前方法不捕获 → 向调用者传播
printStackTrace() 打印完整异常调用栈
new XxxException(e) 抛新异常并保存原异常
getCause() 获得原始异常
finally 即使 catch 再抛异常，一般仍执行
finally 抛异常 可能屏蔽原本异常，应避免
addSuppressed() 保存被屏蔽的异常
getSuppressed() 获取被屏蔽的异常

JDK Logging

  1. 用日志代替 System.out.println()

  2. 使用 java.util.logging.Logger

  3. 创建Logger：
    Logger.getGlobal()
    Logger.getLogger(ClassName.class.getName())

  4. 常用日志：
    logger.severe()
    logger.warning()
    logger.info()
    logger.fine()

  5. 日志级别：
    SEVERE
    WARNING
    INFO
    CONFIG
    FINE
    FINER
    FINEST

  6. 默认一般是INFO：
    INFO及以上显示
    FINE等较低级别默认不显示

  7. 日志可以：

    • 自动记录时间、类、方法
    • 设置级别
    • 输出到文件
    • 通过配置控制输出

  8. 异常处理中可以使用logger记录错误

动态代理

动态代理主要用于在不修改原有业务类代码的情况下，在运行时为对象的方法统一增加额外功能，例如日志、事务、权限校验、性能统计等。它避免了为每个目标类手动编写代理类，同时实现了业务逻辑和通用功能的解耦。
